# 支持范围与常见问题

更新：2026-10-09。这里区分实现与验收；“支持目标”不表示已完成所有设备和网络验证。

## 平台与客户端

| 项目 | 当前范围 | 验证边界 |
| --- | --- | --- |
| 自动安装 | Debian 12、Ubuntu 24.04；root + 本机 Docker | 隔离 Linux runner 真正安装、配置、备份、更新通过；发行版分别新装仍需持续验证 |
| CPU 架构 | Linux x86_64 有 CI 构建包；安装器识别 x86_64 / aarch64 | ARM 从源码构建路径尚未完整实机验收 |
| Windows | 本地源码开发与检查 | Linux host 网络部署路径不等于 Docker Desktop 支持 |
| 桌面浏览器 | Chrome、Edge、Firefox 为兼容目标；需要 HTTPS、WebRTC、麦克风权限 | Chromium 浏览器真实联调通过；三者独立完整验收尚未完成 |
| 手机 | 响应式界面、触控、语音控制 | 移动语音试验支持；后台、锁屏与系统省电可能中断采集/连接 |
| TS3 | 真实身份协议、Opus、消息、权限、经典服务器头像 | 已有独立 TS3 协议联调及浏览器双向语音；官方客户端全矩阵继续验收 |
| TS6 | 原生生态兼容目标 | 不宣称完整 TS6 互通已验收 |
| 邮件 | TLS SMTP，465 隐式 TLS/其他端口 STARTTLS | 已有 QQ 邮件真实送达反馈；每个部署者需验证自己的服务 |
| TURN | 带认证的公网 TURN 配置 | 长连接凭据刷新及受限网络完整验收仍待进行 |
| 容量 | 网关总目标 50 连接、10 路并发语音 | 不是已测容量；30分钟参考环境资源/P95验收未完成，目标TS许可另行限制 |

## 功能边界

已实现：邮箱验证/找回、多身份与 TS3 兼容导出、频道和成员、频道/服务器/私聊、戳一戳、Opus、耳语、设备/音量/静音、默认 V 可改按键、AI 降噪、经典服务器头像、依 TS 权限的基础管理、持续重连恢复频道、网站后台热加载与中文部署管理。

尚未提供：通用文件传输、屏幕共享、完整组权限编辑器、旧 Speex/CELT 编码、myTeamSpeak 云头像。经典服务器头像有专用受限文件传输，不表示开放了通用文件管理。

按键发言只在网页获得焦点时响应，不是全局系统快捷键。降噪在浏览器设备本地运行；回声消除依设备/浏览器能力，不保证所有键鼠声、混合噪声或外放回声完全消失。加密是两段传输加密，网关能接触语音。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 证书警告、HSTS 阻止访问 | DNS 是否指向正确服务器；AAAA、证书域名/有效期与代理规则。不要跳过证书验证 |
| 注册或找回收不到邮件 | SMTP 授权码、发件人权限、出站限制、垃圾箱；“SMTP就绪”不代表已投递 |
| 登录后没有站点管理 | 先验证邮箱，在服务器 `webts admin` 授权，然后重新登录 |
| `Permission denied` | 当前身份 UID 的 TS 权限、服务器密码与安全等级；站长权限不能替代 TS 权限 |
| 麦克风电平不动 | 浏览器/系统麦克风权限、选中设备；查看采集暂停或处理器错误，重新连接 |
| 网页有发言状态但听不到 | 输出设备/音量/停止收听、浏览器音频暂停、WebRTC连接状态及媒体UDP |
| 自由发言吞首字 | 更新并刷新重连，严格仅保留人声默认关闭；极轻声/过长检测或网络延迟仍需实测 |
| 原生客户端一直显示网页发言 | 更新后刷新重连，检查是否关闭降噪导致显式连续模式；用PTT对照 |
| 语音断线或丢包 | 同时检查浏览器→网关和网关→TS的UDP质量；BGP、网页能开或ping低不等于语音无丢包 |
| 头像不显示 | 经典TS服务器头像权限与文件TCP端口；云头像暂不支持 |
| TOML改了邮箱/服务器却不生效 | 后台加密设置优先；使用网页站点管理或 `webts smtp/server` |

反馈请提供版本、浏览器、复现步骤、错误码和脱敏连接状态。不要附密码、身份私钥、恢复链接、实际配置或整份数据库。[提交反馈](https://github.com/PTPHAP/WebTS/issues)。

## 新增实验性好友私信

Olm v1双棘轮Rust/WASM、文字/图片/贴纸、身份备份、设备接管与阅后即焚已有自动化回归；私有S3兼容存储需要站长另行配置和验证。只支持一台私信设备，没有历史同步。移动布局单独设计；手机语音、Firefox/Edge/真实手机上的完整E2EE和供应商生产兼容仍需实测。不是Signal协议，也不是完整Matrix客户端。详见[好友私信](FRIENDS.md)。
