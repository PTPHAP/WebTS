# 站点名称、图标、协议与页脚

入口：管理员登录 → 顶部齿轮 → **外观、协议与公告**。保存前复核当前管理员密码，保存后无需重启；当前页面立即更新，其他访客刷新后读取。基础配置的 SMTP、TS 地址和图片限制与这些内容分别保存，不会互相覆盖。

## 名称与图标

站点名称最多40个字符，用于页头、首页标识、页脚和浏览器标题。图标采用现有正方形裁剪；输入支持 PNG/JPEG/WebP，原图最多2MiB，浏览器裁剪为PNG，服务器验证最多64KiB与512边长并重新编码。用于页头和页签图标，移除后恢复软件默认图标。不要上传SVG、HTML或身份文件。项目许可署名和“Powered by WebTS”仍保留。

## 独立协议页面

所有页面底部均有站内 `/privacy` 与 `/terms` 入口，登录页也提供阅读入口；可以直接打开，无需登录。默认模板来自仓库 [PRIVACY.md](../PRIVACY.md) 与 [TERMS.md](../TERMS.md)。后台可编辑正文、运营者名称、公开联系与数据申请渠道、部署地区、主机/SMTP/TURN等接收方、日志及备份期限、注销与申诉流程。

这些内容全部公开，不能填写密码、授权码、数据库或私钥。软件不会自动把注册邮箱或SMTP账号填成公开联系方式。缺少运营资料时页面明确显示尚未公示，不虚构运营主体或保存期限。模板不是法律合规认证；应与实际业务、接收方及保存方式一致，修改处理目的时做好版本更新和必要告知/授权。

正文支持基础标题、表格、列表、粗体与HTTPS链接；始终生成安全文本节点，不执行HTML。阅读入口本身不是完整的授权记录系统，也不表示用户放弃法定权利。当前没有自助注销接口，申请需走运营者公示渠道；退出不是注销。数据处理或条款修改不会自动撤销用户的合法权利，免责声明不免除依法不能免除的责任。

## 页脚 HTML

最多16KiB UTF-8。可使用 `div p span a br strong em b i small ul ol li code`；链接仅支持完整HTTPS地址，支持`title`说明。服务端使用固定版本HTML5清理器处理，保存后编辑器返回实际保留内容。

```html
<p>友情链接：<a href="https://example.com/">朋友的网站</a></p>
<p><a href="https://beian.miit.gov.cn/">请替换成真实备案号</a></p>
```

脚本、事件属性、任意CSS、id/class、远程图片、SVG、表单、iframe及嵌入资源均会移除；`javascript:`、`data:`和相对地址不保留。友链新标签打开并设置`noopener noreferrer nofollow`，不会自动加载友链站点。备案号与公示链接需运营者自行核实、填写真实信息，不自动生成备案号。语音空间页脚有高度限制，可滚动查看，避免遮盖麦克风和收听控件。

## 默认协议跟随站名

默认正文的 `{{site_name}}` 是安全文本占位符：修改站名后，隐私政策和免责声明自动显示当前名称；项目 WebTS 的软件署名仍保留。自定义协议可使用同一占位符。占位符只替换文字，不用于链接地址，也不会把站名中的 HTML 或 Markdown 当作代码。旧版原封不动的默认模板自动升级；已编辑的正文保留，管理员需要时自行添加占位符。

安装引导先填写站名及公开运营信息再启动站点；后续可运行 `webts site` 修改。这些字段公开，注册邮箱和 SMTP 凭据不会自动复制到其中。CLI 会备份并短暂重启本实例；网页后台保存仍立即生效。
