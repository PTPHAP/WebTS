# 便捷登录与陌生环境

适用于1.1.0源码候选。正式下载包是否包含本功能，以对应版本的发布说明为准；通行密钥、免邮箱注册和匿名访客不在本批范围内。

## 在自己的手机上

首次仍使用已有的邮箱账号登录或注册并验证邮箱。可以选择“记住登录”，最长30天，主动退出、封禁或重置密码可提前失效。在“账号与个人资料”设置独立登录用户名，以后可输入用户名或邮箱配合原密码登录。用户名4至32位英文字母、数字或下划线，以字母开头，不区分大小写，不可与其他账号重复；设置/修改须验证当前密码。

登录用户名不是社区昵称，不改变账号、好友、TS身份、UID或服务器权限。原邮箱仍用于验证与密码找回，邮箱不能收信时不会自动绕过找回验证。

## 在网吧或借用电脑上

1. 自己打开可信站点地址，在登录页选择“手机扫码”。阅读协议并主动勾选后生成二维码。
2. 用手机相机扫码，打开同一站点。手机需要已经进行个人设备登录；如果尚未登录，先登录再确认。无需在电脑上输入邮箱密码。
3. 核对请求中的站点、浏览器与系统，在手机输入面前电脑显示的4位核对码，点击允许。
4. 回到电脑，核对与手机一致的账号编号，主动点击确认。扫码与手机确认都不会自动让电脑登录。

二维码2分钟有效，过期后重新生成；关闭或切换登录入口会尽力取消该请求，网络异常时仍以服务端到期为准。请求只能领取一次，重复点击或迟到请求不能重复授权。网络超时不代表服务器一定没有完成操作；遇到结果不明时刷新核对，并在个人设备安全中心查看会话。

扫码登录始终启用陌生环境模式。也可以使用用户名/邮箱与密码登录，并自行勾选“陌生环境／公共设备”。此选项不作为账号全局偏好同步给自己的手机。

## 陌生环境具体限制

| 项目 | 行为 |
| --- | --- |
| 登录 | 浏览器会话Cookie，不设置长期Max-Age；服务端最多4小时，到期需重新登录 |
| 记住登录 | 禁止与陌生模式同时开启；直接篡改请求也不能得到30天公共会话 |
| 网站管理 | 不授予本站后台和社区审核权限，即使账号本身为管理员 |
| TS身份 | 可使用本人已有托管身份连接；创建、导入、修改、导出和删除身份需在个人设备操作 |
| TS权限 | 仍由真实TS身份和目标服务器判断，公共模式不替代或增加TS权限 |
| 好友普通私信 | 仅按已有发送模式与关系使用，不在本地新增聊天历史；本站可解密，界面保留原有说明 |
| 好友E2EE | 不加载或保存本机设备身份，不启用/恢复/接管设备，不自动切换已有加密方式；服务端拒绝使用设备租约 |
| 频道密码 | 不读取或保存本浏览器的频道密码；需要时本次手动输入 |
| 离开 | 明确退出当前设备；也可从个人设备安全中心撤销这条会话及其TS连接 |

浏览器在使用期间必须持有会话Cookie，不能承诺“任何凭据都不落盘”。浏览器会话恢复、系统或扩展的密码管理器由用户环境控制；网页关闭事件也不能作为可靠退出证明，因此服务端独立执行到期与撤销。陌生模式不会清除这个浏览器以前保存的数据或其他登录，也不能擦除已显示、被复制或截图的内容；建议使用全新的隐私窗口，离开时退出并关闭窗口。

扫码领取后，电脑是一个独立临时会话：退出手机本身不会自动退出已经授权的电脑。需要结束电脑访问时，使用手机安全中心撤销对应会话或退出全部设备；密码重置仍会撤销全部旧登录。一个浏览器的多个标签页可能共享Cookie，登录或退出可能影响其他标签页。

## 安全边界

- 手机确认需要当前有效、未封禁的个人设备会话；公共会话不能继续授权其他设备。授权后到领取前撤销手机会话、封禁或更新协议，领取会失败。
- 二维码中的手机确认凭据与电脑持有的领取凭据不同，服务器只保存两者摘要；链接放在URL片段，页面读取后清除，不放到查询参数、本地存储或邮件里。
- 核对码和浏览器/系统名称帮助确认操作意图，不能证明物理设备身份。浏览器标签可伪造，普通扫码也不能承诺抵抗实时转发钓鱼；只扫描自己在可信地址主动生成的二维码，不扫描别人转发的登录码。
- 已被控制的电脑、恶意扩展和站点运营者不在浏览器功能可消除的风险内。公共模式减少长期凭据与设备密钥使用，不是终端安全认证。
- 账号登录不等于恢复端到端私信身份；个人设备上的E2EE备份、信任与实验标识保持原边界。

## 升级与回退

先备份数据库/WAL、配置和原主密钥。迁移新增`login_names`、短期`quick_logins`和`session_details.public_device`，不覆盖原账号、身份或会话；原会话默认按原有个人登录处理，原邮箱与密码继续有效。短期请求最多1000条，过期请求在新建时清理，轮询按有效请求单独限流。

旧程序不理解公共会话的权限限制，不能直接带着新建公共会话回退。优先向前修复；必须回退时先停新版本，在受控备份和维护流程中撤销全部公共会话、取消未完成扫码请求，再确认旧版兼容。不能把旧数据库备份覆盖到当前库，丢掉升级期间的新资料或消息。登录用户名在旧程序中不可用，但邮箱仍是兼容入口。

本候选管理脚本在新程序就绪检查失败时停服并保留现场，不再自动降级。这个修正不能追溯改变已启动的旧版更新脚本：首次升级应安排维护窗口、停止对外写入，并使用本版本管理流程或手动部署；不能依赖旧版的自动回退来保证兼容性。正式旧版到新版的跨版本安装验收仍需独立完成。

无须购买第三方登录服务或配置新的平台密钥。扫码使用本站HTTPS和现有登录Cookie，不依赖QQ/微信开放平台。正式发布仍须满足[发布门槛](RELEASE-GATES.md)，不以测试数量代替独立安全认证。
