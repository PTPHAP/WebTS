# 对象存储配置：雨云与 S3 兼容服务

WebTS 使用 **S3 兼容 API**，也可以连接雨云 ROS。桶保持私有，浏览器不直接访问桶；好友正文、图片和表情先加密，网关再用部署密钥 AES-256-GCM 包裹后保存。密钥只填写在自己站点的管理后台，不要提交到仓库或 Issue。

## 雨云怎么填

登录站长账号 → **站点管理 → 加密临时存储**，选择“雨云 ROS”：

| 配置项 | 填写方法 |
| --- | --- |
| API 端点 | 使用雨云控制台给出的 HTTPS S3 API 地址；预设为 `https://cn-sy1.rains3.com`。不填桶的公开网址、CDN、路径或查询参数 |
| 桶名 | 复制准确的桶名；当前支持小写字母、数字和连字符 |
| Region | 雨云没有提供时可留空，保存时使用兼容签名值 `us-east-1`；这不会把桶迁往美国。不要填写账号编号或套餐编号 |
| Access Key / Secret Key | 使用属于该桶、允许固定前缀读写删除的专用密钥；原凭据留空表示保留，不会回显 |
| 保留天数 | 默认 7 天，可选 1–30 天；只影响之后发送的消息 |
| 当前管理员密码 | 复核网站密码后保存；设置热加载，无需重启 |

API 端点以控制台实际地址为准。雨云官方示例使用 S3 SDK 和上述预设端点：[雨云 Python 接入文档](https://www.rainyun.com/docs/products/ros/practice/python)。`us-east-1` 是 WebTS 的兼容默认值，已在一个实际雨云桶完成验证，不代表所有地区或供应商都接受相同签名区域。其他 S3 服务填写其明确要求的 Region。

保存后重新输入网站密码，点击 **检测已保存的配置**。检测会创建一个很小的随机加密测试文件，依次上传、读回比对、删除；它不会读取或修改用户消息。修改表单后须先保存再检测，避免检测旧值。后台只显示允许列出的 HTTP 状态和错误代码，不显示凭据或供应商原始响应。

## 权限和生命周期

- 关闭公开读取、公开 ACL；不需要开放浏览器 CORS，也不需要公开下载链接。
- 只授予 `webts-temporary/*` 的 GetObject、PutObject、DeleteObject。WebTS 不需要列举所有桶或访问其他目录。
- 为 `webts-temporary/` 配置与保留期一致的生命周期兜底删除；太短会提前删掉未过期消息。
- 临时桶建议不启用版本保留或对象锁；如已启用，另行清理非当前版本、复制目标和备份，不能把删除当前对象等同于物理擦除所有副本。
- 云端若有 IP 白名单，允许部署网关的实际出口 IP；校准部署服务器时间。

端点只允许公网 HTTPS 443，执行证书校验、DNS 地址检查和固定解析，不跟随重定向或系统代理。传输最多 2 个并发、单份密文 384KiB，受超时和消息配额限制。

## “仍有临时对象，不能迁移存储桶”

这是防止旧消息丢失、旧对象无法清理的保护。后台显示总索引、待完成、已过期和待清理检测文件的数量；这些是数据库索引数，不是扫描桶的结果。

**同一个桶可以直接修正 Region、轮换凭据或关闭新发送**，即使仍有旧对象。Region 不再被当作桶的位置；端点的根目录尾斜杠也不会触发迁移。修改 API 端点或桶名会改变存储位置，须等消息和检测对象清理完成、没有正在传输的对象后再保存。当前没有跨桶自动迁移或强制丢弃旧消息按钮。

关闭开关只停止新发送，原消息仍按原期限读取和清理。到期后 API 立即拒绝读取，后台每 10 秒尝试删除；尚未完成的上传超过一小时后回收，失败检测的遗留对象超过五分钟后回收。网络或权限故障时保留索引重试，禁止通过清空数据库来绕过保护。先修复原桶的删除权限，再检测并等待清理。

## 常见错误

| 结果 | 检查项 |
| --- | --- |
| `AccessDenied` | 准确桶名、密钥所属桶、读写删除授权和出口 IP 白名单 |
| `InvalidAccessKeyId` / `ExpiredToken` | 有效访问密钥；更换 Access Key 时同时填写对应 Secret Key |
| `SignatureDoesNotMatch` / `AuthorizationHeaderMalformed` | Secret Key 是否匹配、Region 是否符合供应商要求 |
| `NoSuchBucket` | 桶名和 API 端点是否属于同一服务实例 |
| `RequestTimeTooSkewed` | 部署服务器时间及时间同步 |
| 上传成功、读取失败 | GetObject 权限、生命周期、服务端是否返回相同密文 |
| 删除失败或仍有检测对象 | DeleteObject 权限；保留原配置修复后重试，生命周期作为兜底 |
| 无 HTTP 状态 | HTTPS 地址、证书、DNS、网络和超时；不关闭证书验证解决 |

2026-10-11 的一次实际雨云联调发现：该端点对附带可选 `Content-Type` 的签名请求返回 `AccessDenied`，去掉该头后同一套密钥的 PUT/GET/DELETE 全部成功。WebTS 已移除这个不必要的头，并加入回归测试；不能仅凭一个 403 判断用户密钥错误。后端检测仍用于判断你的实际配置。
