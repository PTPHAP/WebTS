# TeamSpeak同机语音节点 · 反向连接预览

默认关闭，当前已发布节点包为preview.8（1.1.3）；旧反向节点继续兼容。公网IP映射修复和直达发言控制需要更新TS机器上的节点程序，原有配对与配置保留。[安装与端口教程](NODE-INSTALL.md) · [审查记录](SECURITY-REVIEW-VOICE-NODES.md)。真实目标主机、通话和长期容量须现场验收，安装检查不等于完整语音验收。

```text
浏览器 ←HTTPS/WSS→ 主站 ← 已认证WSS，由节点主动建立 ← TS同机节点
浏览器 ← DTLS-SRTP加密UDP直达 → TS同机节点 ← 固定回环TS端口 → TS
```

节点不需要公开HTTP/HTTPS或管理接口，只放行配置的语音UDP，用户能看到语音公网IP。主站中断仍会影响授权和通话；这不是离线自治节点，也不是浏览器原生TS UDP。延迟取决于实际网络、ICE/TURN与机器负载，须测量。

## 配置与通道

主站后台按既有服务器选择主站转发或同机节点；节点标识和独立随机密钥保存在加密设置中，密码复核后热生效，API不回显密钥。旧启动配置`voice_nodes`仍兼容，后台同ID/同服务器绑定可接管而保留原密钥。节点路线不用于用户自填地址。握手交付登记目标，节点只拨固定回环；地址变化或节点失败明确拒绝，不自动降级。停用/轮换/切回主站撤销旧通道及未领取码；修改绑定地址须先显式切主站。

主站/api/voice-nodes/tunnel只接受已配置节点。HMAC-SHA256覆盖节点ID、GET、完整路径/查询、时间和单次nonce；时间差30秒，重放表最多8192条。TLS正常验证，不接Origin/Cookie，不给浏览器节点密钥。主站最多2条备用通道/节点；每通道只桥接到节点配置的回环HTTP监听，不能从网络指定其他目的地。内层机器API再认证，复用既有网关，不是任意HTTP代理。

帧16KiB、虚拟流32KiB、发送5秒、就绪5秒、外连握手8秒、心跳10秒/存活45秒。主站总通道预算为2×站点连接上限＋2×节点数，每节点同时就绪握手最多2条；节点任务最多连接上限＋2。重连1至30秒退避，取消结束任务。短请求完成后交换关闭帧再释放TCP，避免最后响应被重置丢弃。资源边界不等于容量验收或DDoS防护。

业务命令入站256KiB、主站接收节点事件1MiB，大频道树可能触及兼容上限。图片限制暂独立配置，不随主站热加载，两端取较严者。TS文件传输限定固定回环TS及明确配置的文件端口，不能利用服务器通知转向其他本机端口；没有全局私网放行。

## 配对与权限

后台为每节点生成独立随机密钥并保存绑定；高级手动配置可继续使用独立密钥文件。后台管理员重验密码后生成256位一次性码，主站仅存摘要，5分钟内有效且不超过会话期限；新码使前码失效。领取重新检查邮箱验证、管理员权限、封禁、会话撤销和公共设备限制，拒绝Origin/Cookie；并发最多一次成功。配对码不能创建未配置节点或改变TS目标。

向导仅连接管理员输入并正常验证TLS的主站，无重定向，响应有上限，核对节点ID和主站地址；确认本地可写且节点已停后才领取。沿用既有密钥ACL，配置保存失败尝试恢复原密钥。配置与密钥是两个文件，掉电或文件系统故障下不承诺跨文件原子事务，应保留安全备份。成功配对独立于发码管理员后续登录；后台停用或轮换会撤销旧通道；新密钥需重新配对，无需重启主站。

登录、身份归属、撤销、同UID租约仍由主站判断。仅交付当前连接所需TS私钥/UID/昵称/TS密码、内部账号与连接编号和期限；不交付邮箱、网站密码、Cookie、会话摘要、部署主密钥或其他身份。网站管理员不会获得额外TS权限。

新版发言开关通过仅承载启停、预卷标志和序号的DTLS/SCTP通道直达节点，不经过主站中转；消息128字节、40次/秒、接收窗口8192字节、发送缓冲4096字节，协商消息上限1024字节。额外远端创建的通道关闭，反复创建撤销该连接；非法控制关闭控制通道并回退WSS，不退出正常语音。跨路径序号避免旧命令覆盖新状态，watch仅保留最新值，取消与Drop停止任务。保留TS权限、加密检查与有界首字预卷，不削减AI降噪/AEC。

## 加密与隐私

节点能接触当前TS私钥和声音，必须由可信运营者管理。不复制账号库，仅使用内存运行状态，不将连接身份写库；不新增录音或TS聊天持久化。OS/云/代理日志由运营者管理和公示。

浏览器DTLS-SRTP优先AES-256-GCM、AES-128-GCM兼容下限，TS侧保持原生语音加密检查，不宣传为TS侧AES-256或语音E2EE。好友Olm私信不受此路由影响。UDP直达暴露节点语音IP；主站及节点认证不替代主机加固、更新和网络防护。
