# AFK 与站点账号管理

## AFK / 暂时离开

连接服务器后，点击语音栏 **Zz / 设置 AFK 离开**，填写离开留言并确认。WebTS 将发送 TeamSpeak 原生 `client_away` 和 `client_away_message`，原生客户端和网页成员资料均可看到状态。再次点击 Zz 取消离开。

状态与留言的语义参考 [TeamSpeak 客户端开发文档](https://teamspeakdocs.github.io/PluginAPI/client_html/ar01s22.html)，使用项目固定版本的开源协议库发送客户端状态更新。

离开期间暂停发送麦克风，保留收听、聊天和当前频道；取消后沿用原来的静音状态与发言模式，不会强制开麦。网络自动重连会恢复 AFK 留言，手动断开后重新连接默认在线。参数校验失败会显示错误并恢复确认过的本页状态；TS 服务器拒绝或响应超时时停止连接，避免本页与服务器的离开状态不一致，请重新连接。服务器的频道或 AFK 插件规则仍由服务器决定。当前提供手动 AFK，不读取系统全局空闲时间。

## 管理入口

管理员登录后点击页面右上角 **站点管理**，默认打开 **账号管理**；**基础配置** 保留 SMTP、默认 TS 服务器和自定义连接策略的热加载设置。初始化管理员见 [配置教程](CONFIGURATION.md)。

账号页提供：

- 全站账号、已验证、封禁、管理员及有效登录会话统计。
- 邮箱部分内容搜索，正常、待验证、封禁、管理员筛选，每页 50 条。
- 账号 ID、邮箱验证与角色、注册时间、最近登录、身份数、有效会话数和当前网关连接数。
- 账号详情中的身份名称与 UID、默认身份、内部管理备注和最近 30 条管理操作。
- 永久或 1 小时 / 1 天 / 7 天 / 30 天封禁、提前解封、退出全部设备、授予或取消网站管理员角色。

旧账号此前未记录注册和登录时间，显示“尚无记录”，不会虚构历史时间。新账号开始记录注册时间，每次成功登录更新最后登录时间；连接数为当前网关进程的活动连接，需点击刷新获取最新值。详情最多展示 100 个身份，不回显私钥、密文、会话令牌或密码哈希。

## 封禁和权限

所有修改都需要输入**当前管理员自己的密码**。封禁须填写原因。封禁、强制退出及角色变更会撤销目标的全部登录会话并停止其活动 TS 连接；账号身份和密钥保留。封禁期间无法登录，即使通过旧找回链接重置密码，也不会解除封禁。

临时封禁到期自动允许重新登录，无需定时任务；解封不会恢复旧 Cookie 或旧连接。管理员无法封禁自己、强退自己或修改自己的管理员角色；至少保留一位未封禁的已验证管理员。仅已验证、未封禁的账号可授予管理员角色。变更角色后目标需重新登录。

网站管理员是站点层面的可信管理者，拥有站点设置和账号管理能力；**不会获得目标身份的导出接口或额外 TS 权限**。封禁网站账号不会删除、封禁其 TS UID，也不能阻止该身份在原生客户端独立连接 TS。若需要封禁原生客户端，应由有权限的 TS 管理员在 TS 服务器操作。

不允许后台代改用户密码、跳过邮箱验证或冒充用户登录。用户通过自己的邮箱找回密码。后台操作记录保存执行管理员、目标、操作类型、原因或备注、时间；请勿在备注中填写密码、私钥等秘密。运营者需制定审计和备份保留期限，并更新自己的 [隐私政策](../PRIVACY.md)。

## 管理 API

仅同源、已登录的网站管理员可调用，写入还须复核密码，并在数据库事务内再次检查管理员角色和会话。

| 接口 | 内容 |
| --- | --- |
| `GET /api/admin/accounts?search=&status=&page=0` | 搜索、筛选、分页和统计；`status` 为 `active` / `pending` / `banned` / `admin` 或空 |
| `GET /api/admin/accounts/{id}` | 账号、身份公开元数据与最近操作 |
| `POST /api/admin/accounts/{id}` | `password`、`action` 和对应参数；操作为 `ban` / `unban` / `revoke` / `role` / `note` |

`ban` 使用 `text` 原因及 `seconds`（0 为永久，最长 366 天）；`role` 使用 `is_admin`；备注及原因最多 500 字。账号管理与基础配置写入共用严格的认证限流。
