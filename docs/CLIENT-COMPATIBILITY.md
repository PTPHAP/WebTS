# 原生客户端适配状态与下一步

目标是使已有TS身份、频道、权限与语音操作在浏览器中自然互通。实现功能与正式兼容验收分开记录；不宣称已与全部TS3/TS6客户端或插件完全一致。

| 领域 | 已有功能 | 达到完整客户端体验还需完善/验收 |
| --- | --- | --- |
| 账号、身份 | 邮箱验证/找回、多身份导入创建导出、UID与加密托管 | 官方TS3/TS6 GUI导入导出UID、找回后旧设备与连接撤销的持续验收；自助注销及备份轮换 |
| 语音 | Opus、自由/自定义按键发言、本地RNNoise/GTCRN、回声处理、设备、独立音量、耳语、AFK及提示音 | Chrome/Edge/Firefox及手机真人对照、长期断网恢复、TURN长连接刷新、不同设备/网络的首字与灯效、延迟丢包测量 |
| 频道 | 原生顺序、spacer、BBCode与受限原生图片、单击预览、可调布局和介绍高度 | 服务端图标、组徽章、订阅状态、更多原生状态显示；旧编码仍不支持，频道必须Opus |
| 管理与菜单 | 当前身份创建/编辑/移动频道、空叶频道删除、成员移动/踢出、私聊/戳一戳；频道/成员菜单 | 完整组权限编辑、权限概览及更全面的状态提示；所有操作继续由TS服务器授权 |
| 头像与资料 | 账号固定资料、原生头像读取与同步、裁剪、可配置图片限制 | 多服务器权限/大小限制和客户端缓存行为的正式GUI验收；TS3文件传输仍不是语音链路同等加密 |
| 聊天与生态 | 频道/服务器/私聊、原生安全格式、音乐机器人加密包兼容 | 用户实际音乐机器人安装与真人试听、不同SDK版本互通；发送端明文不能靠网页“补加密”解决 |
| 文件与分享 | 只实现受限的头像和频道图片读取 | 通用文件传输、屏幕共享和完整插件生态仍为后续范围 |
| 容量与发布 | Linux包、源码安装、中文管理、Docker及HTTPS | 独立Linux2核4GB环境的50总连接/10语音/30分钟资源与P95延迟验收；按各TS许可容量测试 |

优先继续：真实浏览器与原生客户端音频/重连验收 → 服务端图标、组和订阅状态 → 完整权限操作与生态互通。通用文件传输及屏幕共享需单独设计安全边界；不会为了兼容明文机器人而关闭语音加密。
