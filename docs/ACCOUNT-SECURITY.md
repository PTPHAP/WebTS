# 账号安全中心

1.1.0源码候选新增[便捷登录与陌生环境](QUICK-LOGIN.md)：可设置登录用户名，手机确认扫码登录电脑，公共会话最多4小时并显示在会话列表中。公共会话只能查看列表，撤销其他会话和修改敏感资料需在个人设备操作；退出当前公共会话仍可用。原邮箱验证、密码找回和个人设备最长30天记住登录保持。

适用于1.0.8及后续维护版本。1.0.7不含此页面；升级请使用同一版本的前后端与安装包。

## 入口与操作

登录后，在社区首页点击“账号安全”，或打开右上角个人账号，选择“账号安全 · 登录设备与会话”。此页面仅查询自己的会话，不需要站点管理员权限。

列表优先显示当前登录，随后显示最近的登录会话，最多50项，并显示全部有效会话总数。可以查看粗略浏览器/系统名称、登录和最晚失效时间，以及是否选择记住登录；旧版本未记录的信息显示为缺失，不根据到期时间推算历史。

点击“退出此会话”或“保留当前登录，退出其他会话”，核对目标并输入当前网站密码，确认后执行。成功后列表重新读取，成功提示自动消失。操作其他会话不会退出当前登录，也不会更改TeamSpeak权限或删除绑定身份。结束当前登录和全部登录仍使用原账号菜单中的退出按钮。

退出会撤销对应Cookie的后续访问，并取消该会话在本站网关的TS连接。一个会话可被多个标签页共用，撤销它会影响这些标签页；保留当前会话也会保留共用它的标签页。这不是物理设备管理或实时在线列表。若怀疑密码已泄露，应通过邮箱重置密码，旧会话会全部撤销；仅退出设备不能阻止知道密码的人再次登录。

## 失败与隐私边界

- 列表仅在打开或主动刷新时查询，没有额外定时轮询；关闭页面取消未完成请求。列表失败或账号不匹配时清除旧列表和待确认状态。
- 网络超时可能发生在服务器已完成操作之后。刷新列表确认结果，不根据请求取消承诺服务器没有执行。
- 管理编号为独立随机引用，不能用于登录。API不返回Cookie原文、令牌摘要、邮箱、TS身份密钥或其他账号的会话。
- 名称来自请求中可被伪造的粗略浏览器/系统标识，仅帮助辨认。本功能不保存IP、完整User-Agent、硬件编号、地理位置或设备指纹。
- 撤销时会话附属记录随之删除。过期会话不能使用，后续登录清理过期记录；数据库备份保留时间由站点运营者说明。
- 退出不能删除已经解密的消息或收回已复制的密钥。端到端密钥备份和设备接管仍遵循[好友私信说明](FRIENDS.md)。

## 升级与回退

升级前停服并备份数据库/WAL、配置和原主密钥。升级只新增`session_details`附表与会话归属索引；原`sessions`三列结构、Cookie凭据、身份密文和部署密钥保留。旧会话的未知登录时间和设备信息不会补造。

附表迁移在事务中执行，重启可重复执行；会话删除通过外键级联删除附表记录。旧版本仍能使用原三列登录结构，但不提供安全中心；再次升级时补录旧版本新增会话的独立编号，未知字段保留缺失。先在隔离副本验证兼容，不直接覆盖生产数据库或密钥。回退程序不能整库恢复旧备份，否则会丢失升级期间的新消息等数据。

本功能不改变语音加密、Olm、站点管理员权限或TS服务器权限。自动化与静态复核不等于外部独立安全认证；正式发布仍遵循[发布门槛](RELEASE-GATES.md)。
