# 网站账号与TeamSpeak身份

邮箱账号负责网站登录和找回；TS私钥证明实际身份，UID对应的服务器组和频道权限由TS服务器维护。

## 首版预定操作

- 导入TS3官方导出的.ini身份或兼容身份字符串，不能仅输入公开UID。
- 网页创建新身份，显示UID；新身份没有旧身份的权限。
- 一个账号保存多个身份，可改名、选择默认、导出和删除；重复UID去重。
- 导出身份前验证当前网站密码；导出文件含私钥，应保密并自行备份。
- 导出后在原生TS客户端导入，UID必须一致。TS6按照实际验证过的兼容导入或同步流程使用。
- 切换身份要重新连接，不能将两份身份的权限合并。
- 找回网站密码后身份密文保留，部署主密钥必须仍可用。

## 待验证

官方文件外壳解析、混淆密钥的恢复、计数器保留、TS3原生导入、TS6兼容流程，以及各身份实际权限一致性。
