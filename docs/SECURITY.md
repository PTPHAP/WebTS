# 安全与信任边界

## 便捷登录与公共设备

1.1.0源码候选加入独立登录用户名、两端主动确认的扫码登录和公共设备会话。用户名只作为登录别名，不替代邮箱验证、当前密码或账号ID；更改须验证当前密码。所有数据库查询使用绑定参数。

扫码请求使用相互独立的256位随机手机确认凭据与电脑领取凭据，数据库仅存摘要；两分钟有效、最多1000个待处理请求，领取事务只能成功一次。手机输入面前电脑的核对码并确认，电脑核对账号编号后再次确认；服务端分别检查两个页面所确认的账号，防止跨标签页Cookie切换改变授权对象。授权会话撤销、封禁、过期或协议更新后不得继续领取。二维码不是通行密钥，不能证明物理距离或抵抗实时转发钓鱼。

公共设备会话最多4小时，Cookie不设置长期Max-Age，服务端拒绝“公共设备＋记住登录”。网站管理员角色、身份管理、端到端设备租约、模式切换和继续授权其他设备受服务端限制。网页不读取或新增本机E2EE身份、信任记录及保存的频道密码。它不清除已有浏览器数据，也不能控制恶意扩展、浏览器恢复会话或系统密码管理器。限制、注销、迁移和禁止直接回退旧版的原因见[便捷登录说明](QUICK-LOGIN.md)。

扫码轮询按有效请求限额30次/分钟；创建和领取另有公网IP粗限额，与原有全局入口、工作队列和数据库上限共同约束资源。没有从这些上限推断大型社区容量已通过验收。


## 近期语音诊断与站点举报

近期质量仅保留有限数值计数，不保存原始RTC报告、候选地址或设备信息；脱敏诊断文件由用户主动下载，不自动上传。音频转发队列有包数与时间上限，关闭连接明确停止接收任务。网络与麦克风恢复不会降低语音加密要求。

举报内容为用户主动提交的管理材料，通过HTTPS传输，以现有AES-256-GCM托管机制保存，账号/举报编号/用途参与认证上下文。请求指纹使用标准HMAC-SHA256，避免数据库泄露后直接对举报原因做无密钥摘要猜测。处理说明、内部备注及历史材料均加密保存；必要权限元数据不声明为隐藏。管理员能读取这些材料，这不是E2EE；系统不会自动获取好友私信或提供私信解密后门。

所有新举报接口核对页面账号、有效会话及对象可见性。管理读写在数据库锁/事务内复验当前角色，处理版本冲突时拒绝覆盖；幂等请求、文本与数量上限、有界分页和保留期限用于控制重试及资源消耗。清理数据库记录不代表安全擦除介质或历史备份，运营者须公示备份期限并保护部署密钥。

## 社区功能的权限边界

频道邀请与二维码不是授权令牌；实际加入仍由 TeamSpeak 服务器裁决。活动创建、报名和读取接口已移除，保留旧表用于按期清理及历史举报处理。

收藏字段采用固定白名单，不保存密码或私钥；诊断导出不提供原始 RTC 日志、IP 或设备标识。历史活动正文仍为站点托管密文，运营者可解密，按期清理。公开运行概览仅管理员可见且只包含聚合计数，不是容量认证。详细用法与保留期限见[社区文档](COMMUNITY.md)。

安全回归、自查与依赖漏洞扫描不能证明“没有任何漏洞”，也不能替代 E2EE 独立审计、真实设备及正式安装包验证；验收标准见[发布门槛](RELEASE-GATES.md)。

数据种类、接收方、保存期限与用户控制见 [隐私政策](../PRIVACY.md)。部署前应补齐实际运营者信息。

站点可自定义外观及协议，见[配置说明](SITE-CUSTOMIZATION.md)。页脚是唯一允许受限HTML的站点字段：固定ammonia清理器仅保留被动标签和HTTPS链接，不允许事件/CSS/媒体/表单/嵌入，保存和公开读取均清理；链接强制新标签与noopener/noreferrer。其他公告、资料、政策、TS内容继续以安全节点显示。外观修改要求管理员角色、同源及当前密码复核；旧首页请求不会清空新增字段，基础设置不能覆盖它们。没有自动公开SMTP账号或注册邮箱的逻辑。

## 必须保持的约束

网页好友元信息响应核对所属账号；查询失败隐藏旧会话。私信解锁还核对本地身份所属账号，新公钥登记请求显式提交目标账号，服务端与当前认证会话比较后才允许执行。旧接口不带该字段仍需当前密码与有效会话，以兼容旧客户端；更新后应刷新页面以使用新的上下文保护。账号核对不是认证替代，也不提供跨设备历史或自动加密降级。

- 验证邮箱、Argon2id密码哈希、可撤销安全Cookie；找回令牌短时且单次使用。
- 重置密码或退出全部设备立即撤销登录，并取消相应的活动TS连接。
- 每次身份读取和使用都检查当前登录用户归属；不存在“只填UID即可绑定”。
- 私钥密文使用AES-256-GCM认证加密，关联账号与身份元数据；部署主密钥不进数据库/Git/镜像。
- 服务端托管意味着站点运营者或被攻破的网关可能使用私钥。文件持有者可以取得对应TS身份权限。
- 禁止记录私钥、密码、恢复令牌、聊天内容和音频。协议库的原始命令/包调试输出在正式运行中关闭。
- WebRTC允许AES-GCM、禁止明文降级；TS服务器必须全局语音加密，普通音频和耳语同样验证。
- TS加密算法依实际协议实现验证，不把AES-128-EAX写成AES-256；网关是两段加密的终止点，可接触音频。
- 未配置SMTP时注册和找回不能假装发送成功。HTTP仅用于明确允许的localhost开发。

## 数据备份

数据库和主密钥分别保管。恢复必须同时具备正确主密钥；已有数据库缺密钥时应报错，不自动生成替代密钥破坏可恢复性。

## 首版实施边界

安全Cookie在HTTPS下使用__Host-webts、Secure、HttpOnly、SameSite=Strict；未勾选记住登录时为浏览器会话Cookie，服务端上限12小时。勾选后最长30天，退出和重置可提前撤销。

验证/找回链接15分钟有效，数据库只保存令牌摘要。链接放在URL片段，网页读取后清除地址栏中的片段。邮件异步发送，进入队列不等于投递成功；真实送达需由部署者验证。

重新发送验证邮件保留原注册密码，按账号限制60秒间隔；替换旧链接且只处理未验证账号。接口统一响应，避免通过发信结果判断邮箱是否存在。邮件同时提供HTML与纯文本，无外部图片或跟踪资源。

身份接口按Cookie中的当前账号查归属；导出/删除复核当前密码；数据库认证密文绑定账号、身份ID、UID。站点持有解密钥，因此只能使用信任的站点托管TS身份。

同源验证覆盖写请求和WebSocket，浏览器通过React文本节点显示服务器内容，不将聊天或描述解释为HTML。密码计算限制为2个并发工作，邮件32项、信令64项、浏览器音频8包队列，满载拒绝操作或丢弃过时音频。总连接上限包含尚在握手的WebSocket。

普通音频及耳语均要求TS全局加密；策略关闭、未知或协商未满足AES-GCM时停止连接。明文语音包全部丢弃并限频提示，其他已加密语音保持可用。实际浏览器SRTP套件通过连接统计确认；仅协商成功不会代替TS端策略验证。网关模式不执行库中不可取消的身份安全等级线程，高等级需求使用原生客户端处理。

每连接最多128个当前频道及近期耳语成员音频轨道，其他频道的可见成员不占用轨道，每次耳语最多16个成员或16个频道，每账号最多100个身份。会话、身份与目标隔离，但仍需完整原生通话、安全审计及容量验证。TURN凭据1小时到期，长连接刷新尚待验收；公开部署前先测试自己的网络路径。

## 音频处理与头像边界

增强降噪使用同源固定WASM，CSP仅增加wasm-unsafe-eval（不增加通用unsafe-eval）和同源worker。下载/初始化超时、处理器错误会提示并回退；浏览器设备能力影响原生处理是否生效。

公网部署过滤trickle ICE及SDP内嵌候选的私网/回环/元数据/命名目标，避免网关被用作内网UDP探针；仅明确允许的localhost HTTP开发保留本机ICE测试。TURN中继须使用公网地址。

头像绑定当前已验证TS连接，仅用可见成员真实UID生成固定文件路径；TCP目标固定为已验证语音对端IP。请求单次/过期检查、并发2、网络超时、默认下载128KiB、上传64KiB；站点可调整至下载512KiB、上传128KiB。上传解码边长默认512、最大1024，分配预算16MiB。接收原生头像单独限制最长边4096、800万像素、32MiB解码预算，先缩小再按站点保存体积限制重编码为PNG，不提高原文件下载限制。接收PNG、JPEG、GIF及WebP头像，均经受限解码后转为PNG；暂时失败最多自动重试三次，切换连接时取消旧重试。MD5只用作原生头像版本比对，不提供身份认证或内容安全保证。经典TS3头像TCP没有语音加密；只上传可公开图片。网页云头像暂不接入。


## 首页和个人资料

公共 `/api/site` 仅返回已发布首页内容，不返回 SMTP、服务器地址、账号资料或未发布公告。首页修改要求管理员角色和当前密码；基础设置保存保留首页内容。`/api/profile` 以登录会话确定归属，不接受用户 ID，写入时再次检查会话有效期与封禁。所有写接口维持同源校验和有界限流。

账号头像使用已有图片解码/重编码规则；首页图片仅接受 JPEG 数据，服务端限制尺寸、解码内存、单图与总量，重新编码去除附加元数据。默认 API 正文仍为32KiB，仅资料和首页上传接口分别放宽到256KiB和1MiB。昂贵的图片解码使用最多2个后台任务；公告与介绍由 React 作为文本渲染，不支持 HTML、远程图片 URL 或脚本。HTTPS、CSP、HttpOnly Cookie、身份加密与 TS 权限检查继续生效。


## 原生频道渲染与图片


BBCode 使用有界语法树和 React 节点，禁止 HTML、脚本链接、任意 CSS 和远程图片自动请求。ts3image 读取仅限当前连接、可见频道介绍实际引用且目标频道可见的文件，TS 验证本人权限；固定 TCP 对端、请求归属/单次句柄/超时/并发/速率/解码限制继续执行，结果重编码为 PNG。频道图片不会使用 Query 管理权限、其他账号身份或系统文件路径。详见 [显示与音乐兼容说明](TEAMSPEAK-RENDERING.md)。


管理员图片限制仅在角色与当前密码复核后写入加密站点设置，服务端验证整数和安全范围；连接通过已认证WebSocket同步非敏感限制。前端数量/缓存控制用于体验，服务端独立检查图片引用数量、读取速率、文件体积、解码尺寸、PNG体积及原生身份权限。全局频道图片缓冲使用128MiB的KiB计数信号量，在分配文件缓冲前获得预算，预算持有到后台解码结束，取消/超时不提前释放仍在计算中的预算。内存预算、解码任务数与类型/路径/目标约束不允许通过后台关闭。

服务器主页只使用当前连接的 TS 元数据。图标路径由服务器 icon ID 构造，原生图标不可用时可自动读取 TS 公布的主机按钮图片；欢迎介绍中的原生图片仍验证频道可见性、UID、路径和文件权限。外部图片不提供通用 URL 代理：初始地址必须与当前 TS 发布的横幅或主机按钮图片一致，下载完成再次检查元数据。仅允许公网 HTTPS/443、HTTP/80，最多三次跳转；每一跳重新检查全部 DNS 候选并固定解析结果，TLS 保留主机名验证，禁止 HTTPS 降级，禁用系统代理，限时限量、受全局内存预算和有界解码约束，重新编码 PNG。HTTP 图床图片不具备沿途完整性保证，应优先配置 HTTPS；图片兼容不改变账号、聊天及语音加密策略。下载请求不附带用户 Cookie、认证头或站点凭据。跨连接/账号旧结果不可复用。

## 站点信件与协议版本

注册/密码登录须明确同意当前公开协议，后端核对摘要版本并保存账号确认记录，不由前端勾选框单独决定。协议与运营资料改变后旧版本拒绝；已有会话不自动撤销。该机制不替代运营者的真实告知或适用要求。

信件发布/撤回必须为当前有效管理员会话并复核密码，数据库提交时重新核对管理员、封禁、会话到期及撤销状态。正文使用固定Markdown解析器和HTML白名单过滤，外链仅HTTPS、无凭据；内嵌JPEG有字节/尺寸上限并重编码，站内外部图片不自动加载。列表/正文按当前账号收件记录隔离，正文读取只标记该账号已读。发布nonce与内容摘要防重复及误重放，频率/正文/收件人与总存储有界。

邮件同步须用户主动订阅，逐封单收件人投递，经现有TLS SMTP，排队时重新检查订阅、封禁、撤回及发布者管理员权限；正在发送的SMTP事务无法撤回，状态不确定不自动重发。投递队列只随 `serve` 启动，读取/修改配置的CLI不会发通知邮件。请运营者制定通知保留和备份清理；管理员发信权仍能发送误导性内容，用户不应在通知链接输入私钥或密码。

## 好友E2EE与临时存储

私信身份丢失可执行明确确认的重置：同源、当前网站密码复验、签名绑定站点/账号/新旧公钥、事务内会话复核及旧公钥版本比较。重置仅影响当前账号，原好友码/关系/普通消息/TS身份保留；旧E2EE消息立即过期，旧设备租约及预密钥撤销。重复已完成请求不再次撤销新设备。客户端预先加密暂存新身份，原记录在最终提交前保留，本地替换和旧状态清除在同一IndexedDB事务中进行。安全码确认绑定双方当前公钥，升级旧确认需重新核对；这不是旧消息恢复或服务器解密后门。

默认标准Olm v1双棘轮由vodozemac 0.11.1处理，不启用实验v2/fuzzing；签名一次性密钥和核对安全码绑定公开身份。私信身份/棘轮状态在浏览器AES-256-GCM加密后保存，默认使用不可导出的设备CryptoKey，手动口令与可移植备份使用PBKDF2-SHA256 600000次。自动密钥与密文同机存储，同源JS可使用，不承诺抵抗已失陷终端或恶意网站。

普通聊天需有效登录和已接受好友关系，不依赖收件人在线或额外同意，无需端到端设备租约；旧E2EE消息仍需本机设备密钥与安全码核验，普通模式不能读取它们。其AES-256-GCM内容密钥通过HTTPS交给网关，不能称为E2EE。两种模式均由网关部署密钥再次AES-256-GCM包裹后写入私有S3桶；SQLite只存元数据及模式选择。模式版本在上传前后核对，选择变化使未完成上传过期，旧消息不转换。自动设备续租在写事务内再次校验租约，防止并发接管时旧续租重新获得权限；同机丢失确认可重试已持久化租约。端到端设备接管仍需要网站密码，旧设备E2EE私信失效；普通临时消息不因此过期。

有界对象并发、固定前缀、HTTPS证书校验、公网DNS固定、禁跳转/代理、配额、过期立即拒读与后台删除重试。真实供应商未配置不声称联调通过。E2EE接入尚未经过独立密码审计，不能防御恶意网站JS、扩展、已失陷终端或对方保存副本。原生TS私聊不是E2EE。[详细边界](FRIENDS.md)。


## 好友位置、频道密码与偏好隔离

好友位置来自此网关已成功连接的实际TS状态，仅已接受好友且对方开启共享时可读；关联会话撤销/过期/封禁、连接取消、站点目标策略改变会隐藏位置。加入请求重新校验关系及新位置，不转交密码或赋予TS权限。近期在线心跳45秒、每账号最多4个最近会话、全局5000个活动账号记录；容量达到上限时省略新增心跳，不影响登录授权。

频道密码仅在TS确认成功后按账号/服务器UID/地址/频道，用浏览器不可导出的AES-256-GCM CryptoKey及认证上下文保护；30天访问有效期，本机清除旧错误密码，不发给好友、不在账号偏好中同步。自动密钥无法抵抗同源恶意JS或已失陷终端。

账号偏好PATCH仅允许固定非秘密字段、大小与范围；写入携带预期账号ID并在事务内复核会话，合并具体修改字段，拒绝身份、密码和硬件设备编号。旧账号异步结果被前端代次隔离，失败保留最新修改并退避重试。

端到端会话默认后台/失焦遮罩并暂停新的已读确认。Permissions-Policy 禁用此页面的 display-capture 和 camera，保留同源 microphone；CSP及禁止嵌入继续执行。这不能禁止系统截图、外部应用录屏、其他页面采集屏幕、远程控制软件或接收者保存明文。[W3C屏幕采集权限边界](https://www.w3.org/TR/screen-capture/)。

## 并发与异常处理

普通阻塞任务最多8个并行、64个在途请求；密码哈希、图片处理等计算任务独立限制为2个并行、16个在途请求。等待执行最多3秒，满载返回503和Retry-After，不创建无界等待队列；已开始的阻塞任务继续持有配额直至退出。CPU配额不等于已通过容量验收。

已登录账号的读取、写入和敏感操作分别计数，退出有独立限额；公网IP保留较宽的入口与认证上限，邮箱尝试单独计数且不依赖账号是否存在。多人共用出口IP仍受粗粒度防滥用上限约束。找回邮件按账号间隔60秒，冷却期间不替换尚有效的链接。

对象传输最多8个并行、32个在途请求，每账号最多2个；等待有超时，尚未开始的请求取消归还配额。已开始的消息传输在有界任务内继续至结束，持有原配额和同一消息的互斥许可，最终重新复核会话、好友关系及加密模式；取消 HTTP 不等于撤回。删除对象前重新核对当前过期状态，避免旧清理快照误删已完成的重试。存储位置变更仍要求全部传输结束及旧索引清空。过期对象删除失败会记录有界退避，继续处理其他对象，删除成功前保留索引。不能把暂时的上传成功当作长期存储可用保证。

协议握手计算移至最多2个阻塞任务，限制难度、耗时和取消检查，不修改原协议算法。错误Opus帧丢弃并限频记录，不让单个坏帧终止收听者连接。语音会话检查不阻塞音频事件循环，登录到期还有独立截止时间；退出、封禁和身份删除的主动取消继续保留。

可选TURN镜像固定为coturn 4.16.0和摘要；示例关闭未使用的TURN/DTLS监听，不影响WebRTC DTLS-SRTP。升级原因见[上游安全公告](https://github.com/coturn/coturn/security/advisories/GHSA-5x2p-4vqj-f6m4)。使用自定义镜像的运营者仍须自行更新；持续刷新、容量与真实网络路径需要实测。
