# 决策记录

## 2026-10-07 · 独立客户端与固定协议库

采用独立前端和单Rust网关，复用MIT/Apache许可协议库，避免每用户创建子进程。协议库固定提交；修改以小补丁保留，构建可重现。

## 2026-10-07 · 邮箱账号与加密托管

用户选择邮箱密码登录、必须登录才能连接、服务端加密托管多个身份，注册邮箱找回后保留身份。采用SQLite与独立部署主密钥，不用登录密码作为唯一私钥加密密钥。

## 2026-10-07 · 加密优先级

用户选择协议兼容范围内最强，所有语音链路必须加密。浏览器侧AES-GCM，TS侧实际兼容算法，全局强制加密与耳语单独验收。网关接触音频，不描述为全程端到端加密。

## 2026-10-07 · 原始Opus路径

协议库audio特性绑定解码器，网关转封装不需要解码。新增raw-audio特性仅暴露InAudioBuf、事件和已有接收加密检查，保留其原行为。待编译和真实语音验证。

## 2026-10-07 · 长期维护

用户要求长期开发、必要文档和工作进度、未来更新计划持续维护。项目状态、需求清单与交接是续开发入口；任何新要求同步文档及验收标准。
