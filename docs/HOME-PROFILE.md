# 首页、公告与个人资料

## 入口

网站 `/` 是公开首页，`/login` 是登录入口，`/app` 是需登录的语音工作区。顶部“首页”和“语音空间”可直接切换；正在连接时回首页会保留语音，首页明确提示仍在连接。想停止采集或通话，请在工作区静音或断开。

邮件验证及找回链接沿用原有短时、单次令牌流程。匿名访问工作区会转到登录入口，登录成功进入工作区。

## 管理首页

网站管理员登录后，点击顶部齿轮 **站点管理 → 首页与公告**：

1. 修改首页主标题、介绍，上传展示图片；移除展示图片会恢复默认图形。
2. 添加公告标题、正文及可选配图，最多6条；关闭“公开展示”保留草稿，公共接口不返回草稿。
3. 输入当前管理员密码，点击“保存并发布首页”。无需重启，当前页面立即更新，其他访问者刷新即可看到。

图片输入支持 PNG、JPEG、WebP，原文件最多4MiB、尺寸最多4096×4096且总像素不超过8Mi。浏览器压缩为 JPEG，服务端再验证和重编码；单张保存图片最多128KiB，总编码量最多700000字符。所有文字按纯文本显示，不接受 HTML、iframe、脚本、远程图片地址或任意文件。

首页公开，因此不要将邮箱、凭据、身份文件、内部服务器信息或其他私人资料放入公告。普通账号不能访问此编辑器。SMTP/服务器等基础配置保存在独立操作中，修改它们不会覆盖首页内容。

## 我的声音名片

点击顶部账号按钮 → **个人资料 · 昵称与固定头像**。这里可以设置：

| 项目 | 行为 |
| --- | --- |
| 登录邮箱 | 只读，自己和站点管理员可见，不发送给 TS |
| 常用昵称 | 3–30个字符；下次连接默认使用它，连接窗口仍可临时修改；留空使用所选身份名称 |
| 个人介绍 | 最多512字节，中文通常每字3字节；开启同步后用于 TS 的本人介绍 |
| 固定头像 | 随账号保存在网站，不需要每个服务器重新选择；适用于该账号选择的各个身份 |
| 同步开关 | 默认关闭，分别选择是否将账号头像、介绍应用到 TS；选择新头像自动打开头像同步 |

选择图片后点击 **保存个人资料**，修改才能持久保存。头像最多2MiB，PNG / JPEG / WebP；裁切为正方形并压缩成最多256px的 PNG，服务端再验证和移除元数据。换设备、重登或密码找回后仍可读取原资料。

开启开关时，每次连接或保存资料会尝试同步一次。介绍或头像被服务器拒绝，会显示 TS 的拒绝提示；网站仍保留账号默认资料，下次连接其他服务器会再次尝试。不绕过上传、文件传输和本人资料修改权限，也不授予网站账号额外 TS 权限。昵称不会自动改掉活动连接中的临时昵称。

移除账号默认头像或关闭同步会保留各服务器已有头像/介绍；需要删除服务器副本时使用原生客户端或联系该 TS 管理员。网站账号头像是统一默认图，服务器仍各自保存副本；这不是 myTeamSpeak 云头像同步。原生 TS3 客户端可查看服务器头像及介绍；TS6 的完整兼容仍以 [支持范围](SUPPORT.md)为准。

**TS3 头像文件传输不加密**，请只选可公开图片。头像保存独立于身份私钥；个人资料不会修改身份 UID、组或发言权限。

## AFK 提示音

在语音栏选择 AFK 并确认留言，服务器接受后播放离开音；取消成功后播放返回音。提示音遵循“语音与设备 → 提示音”的启用和音量设置。浏览器需要先点击页面以允许音频；拒绝操作、初始快照和重连恢复不重复播放。
