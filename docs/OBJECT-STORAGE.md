# 对象存储配置：雨云与 S3 兼容服务

WebTS 使用 **S3 兼容 API**，也可以连接雨云 ROS。桶保持私有，浏览器不直接访问桶；好友正文、图片和表情先加密，网关再用部署密钥 AES-256-GCM 包裹后保存。密钥只填写在自己站点的管理后台，不要提交到仓库或 Issue。

## 多个存储配置（开发版，尚未包含在1.0.8安装包）

后台可以保存最多8个配置，包括兼容旧数据的“原有存储”。选择“＋ 添加对象存储”，填写名称和该桶的参数，保存后逐个检测读、写、删除权限；再次输入管理员密码，点击“设为默认写入”。切换热加载，不重启语音连接。

- 每份临时消息和检测对象的索引记录独立存储配置编号。默认切换只影响新对象；原消息读取、失败上传重试和过期删除仍使用原配置，不自动复制或迁移，不自动换桶。
- 已有数据自动归属“原有存储”，不重新上传、不重新加密。关闭某个配置的新发送，仍可读取、重试已有发送和清理旧对象；相应权限与期限仍须有效。
- 同桶可修改签名Region、轮换凭据或停止新发送；有对象索引的配置不能修改端点或桶名，也不能删除。当前默认和“原有存储”不能删除。遗留检测对象也会阻止删除，须先恢复删除权限并等后台清理。
- 配置凭据加密保存在站点设置中，管理接口不回显；所有配置共享原有传输并发、账号限额及队列，增加桶不会无限增加传输任务。
- 后台数量是本站维护的索引数，不是供应商实际容量。桶的容量、费用、地域和可用性由管理员核对；没有容量自动换桶或故障自动降级。故障不会把正文或图片保存为服务器本地文件。

当前多存储接入的是好友临时消息与检测对象。账号、权限、对象归属、时间和清理重试等必要元数据仍在SQLite；已有站点公告、个人资料和头像的保存方式不因本功能自动迁移。后续帖子正文、评论和附件接入时，需要独立的长期保留前缀与删除策略，不能直接套用临时消息的生命周期规则。

### 升级、备份与回退

升级前一起备份数据库、原部署密钥与站点配置。数据库新增的存储编号和加密配置必须一起恢复，不能重建或替换编号；每个桶及其版本/生命周期也须单独核对。未知归属会报错并停止访问，不猜测其他桶。

管理员需补充实际使用的所有供应商、地域与期限到站点隐私政策；已有自定义政策不会被软件文档自动覆盖。

旧1.0.8程序不理解多配置设置。启用后不能直接用旧程序覆盖运行，也不能恢复旧数据库来丢弃新消息。需要回退时先在维护环境确认所有非原有存储对象及检测对象已正常清理、默认已切回原有存储，再通过受控配置转换移除新版字段；保留可恢复备份并验证旧程序。不提供强制丢弃对象的按钮。优先向前修复，参阅[备份恢复](BACKUP-RECOVERY.md)。

## 雨云怎么填

登录站长账号 → **站点管理 → 加密临时存储**，选择“雨云 ROS”：

| 配置项 | 填写方法 |
| --- | --- |
| API 端点 | 使用雨云控制台给出的 HTTPS S3 API 地址；预设为 `https://cn-sy1.rains3.com`。不填桶的公开网址、CDN、路径或查询参数 |
| 桶名 | 复制准确的桶名；当前支持小写字母、数字和连字符 |
| Region | 雨云没有提供时可留空，保存时使用兼容签名值 `us-east-1`；这不会把桶迁往美国。不要填写账号编号或套餐编号 |
| Access Key / Secret Key | 使用属于该桶、允许固定前缀读写删除的专用密钥；原凭据留空表示保留，不会回显 |
| 保留天数 | 默认 7 天，可选 1–30 天；只影响之后发送的消息 |
| 当前管理员密码 | 复核网站密码后保存；设置热加载，无需重启 |

API 端点以控制台实际地址为准。雨云官方示例使用 S3 SDK 和上述预设端点：[雨云 Python 接入文档](https://www.rainyun.com/docs/products/ros/practice/python)。`us-east-1` 是 WebTS 的兼容默认值，已在一个实际雨云桶完成验证，不代表所有地区或供应商都接受相同签名区域。其他 S3 服务填写其明确要求的 Region。

保存后重新输入网站密码，点击 **检测已保存的配置**。检测会创建一个很小的随机加密测试文件，依次上传、读回比对、删除；它不会读取或修改用户消息。修改表单后须先保存再检测，避免检测旧值。后台只显示允许列出的 HTTP 状态和错误代码，不显示凭据或供应商原始响应。

## 权限和生命周期

- 关闭公开读取、公开 ACL；不需要开放浏览器 CORS，也不需要公开下载链接。
- 仅启用好友临时消息时，授予 `webts-temporary/*` 的 GetObject、PutObject、DeleteObject；启用社区动态还需授权下文的 `webts-community/*`。WebTS 不需要列举所有桶或访问其他目录。
- 为 `webts-temporary/` 配置与保留期一致的生命周期兜底删除；太短会提前删掉未过期消息。
- 临时桶建议不启用版本保留或对象锁；如已启用，另行清理非当前版本、复制目标和备份，不能把删除当前对象等同于物理擦除所有副本。
- 云端若有 IP 白名单，允许部署网关的实际出口 IP；校准部署服务器时间。

端点只允许公网 HTTPS 443，执行证书校验、DNS 地址检查和固定解析，不跟随重定向或系统代理。传输最多 2 个并发、单份密文 384KiB，受超时和消息配额限制。

## “仍有临时对象，不能迁移存储桶”

这是防止旧消息丢失、旧对象无法清理的保护。后台显示总索引、待完成、已过期和待清理检测文件的数量；这些是数据库索引数，不是扫描桶的结果。

**同一个桶可以直接修正 Region、轮换凭据或关闭新发送**，即使仍有旧对象。Region 不再被当作桶的位置；端点的根目录尾斜杠也不会触发迁移。修改某个配置的 API 端点或桶名会改变存储位置，须等该配置的消息和检测对象清理完成、没有正在传输的对象后再保存。开发版可另加配置并切换默认写入，无需清空旧桶；当前没有跨桶自动迁移或强制丢弃旧消息按钮。

关闭开关只停止新发送，原消息仍按原期限读取和清理。到期后 API 立即拒绝读取，后台每 10 秒尝试删除；尚未完成的上传超过一小时后回收，失败检测的遗留对象超过五分钟后回收。网络或权限故障时保留索引重试，禁止通过清空数据库来绕过保护。先修复原桶的删除权限，再检测并等待清理。

## 常见错误

| 结果 | 检查项 |
| --- | --- |
| `AccessDenied` | 准确桶名、密钥所属桶、读写删除授权和出口 IP 白名单 |
| `InvalidAccessKeyId` / `ExpiredToken` | 有效访问密钥；更换 Access Key 时同时填写对应 Secret Key |
| `SignatureDoesNotMatch` / `AuthorizationHeaderMalformed` | Secret Key 是否匹配、Region 是否符合供应商要求 |
| `NoSuchBucket` | 桶名和 API 端点是否属于同一服务实例 |
| `RequestTimeTooSkewed` | 部署服务器时间及时间同步 |
| 上传成功、读取失败 | GetObject 权限、生命周期、服务端是否返回相同密文 |
| 删除失败或仍有检测对象 | DeleteObject 权限；保留原配置修复后重试，生命周期作为兜底 |
| 无 HTTP 状态 | HTTPS 地址、证书、DNS、网络和超时；不关闭证书验证解决 |

2026-10-11 的一次实际雨云联调发现：该端点对附带可选 `Content-Type` 的签名请求返回 `AccessDenied`，去掉该头后同一套密钥的 PUT/GET/DELETE 全部成功。WebTS 已移除这个不必要的头，并加入回归测试；不能仅凭一个 403 判断用户密钥错误。后端检测仍用于判断你的实际配置。

[好友与加密边界](FRIENDS.md) · [配置教程](CONFIGURATION.md) · [文档中心](README.md)

删除失败按对象保存重试时间，初始30秒，逐步增加至最多1小时；同批其他过期对象继续处理。修复删除权限后，仍需等待对应重试；重启不会取消持久化退避，也不会清空旧索引。

## 社区动态目录（未发布源码候选）

会员帖子、评论和内容举报使用 `webts-community/v1/`，与 `webts-temporary/v1/` 好友临时消息分离。两个目录均为私有对象，仅存AES-256-GCM托管密文；社区共享内容不是端到端私信。为社区目录单独授权 `GetObject`、`PutObject`、`DeleteObject`，不要套用临时私信的天数过期规则，也不要设为公开读取。社区启用前确认当前默认桶允许新目录。旧临时目录检测成功并不证明新目录权限正确。

内容索引绑定原配置；默认切换不搬移旧对象。配置统计包含未清理社区对象，删除记录只有云端对象确认删除后才解除配置占用。后台关闭社区模块仍继续清理；删除失败会退避重试，不先抹掉索引。版本化桶、回收站和备份由运营者另行设置。详见[社区动态](COMMUNITY.md)。头像、首页图片、账号与业务索引当前仍保留原存储方式，不能据此宣称全站零本地数据。

### 社区编辑与分区图标

帖子编辑和分区图标沿用 `webts-community/v1/` 的私有随机对象键，不需要新公开桶。新对象先加密上传，再事务切换数据库指针；版本作为AEAD认证上下文的一部分，旧密文不能替代新版本。旧对象及未完成上传仍按原配置清理，不能因切换默认写入而迁到新桶。占用计数包含当前图标、编辑中对象及删除失败的旧对象。恢复文字图标后旧图仍须确认删除，才能解除原桶占用。请保留原配置读取/删除权限；加密对象不能直接作为公开图床URL使用。
