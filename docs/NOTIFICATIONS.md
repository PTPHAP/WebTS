# 信件、提示音与协议确认

## 用户：右上角站点信箱

登录后点击右上角信封图标；数字表示未读信件。打开一封信会标记已读，左侧可切换其他信件，每页最多50封。站内信保存在账号下，换设备后仍可查看；实时TeamSpeak聊天只留在当前网页连接中。

信箱默认接收管理员站内信。若希望收到更新邮件，主动勾选“同时接收管理员的更新邮件”；默认关闭，可随时取消。该开关只控制更新通知，不影响账号验证或密码找回。首次进入页面只显示未读数；保持页面可见时，约20秒或重新获得焦点会检查新信件并发声。浏览器需先有用户点击才能播放声音。设置→语音与设备可调整提示音开关与音量；原有音量偏好保留。

消息、信件、戳一戳使用不同旋律，戳一戳更突出，聊天也显示约8秒的可关闭提醒；私聊/戳一戳提醒可打开对方独立私聊会话。提示音限频，避免大量消息叠加。浏览器、系统静音或设备输出设置仍可能影响实际声音。

## 管理员：独立“信件与通知”页面

进入右上角站点管理，在“信件与通知”页填写标题、正文及收件范围。可选择全部已验证且未封禁的用户，或使用账号管理中的站点账号ID指定最多100位。发布时固定收件名单，之后注册的用户不会自动收到旧信；网站账号ID与TS客户端ID不同。

支持Markdown或安全HTML，包括标题、列表、表格、代码、HTTPS链接及图片。点击“插入裁剪图片”可从本机图片选择区域，保存为不含原图元数据的JPEG；正文最多192KiB，单张内嵌图片最多128KiB，最多1600×1200像素。图片限制使用通知正文的固定安全上限，不改变TS频道/头像限制。裁剪图片在邮件中转换为CID内嵌附件，避免依赖邮箱对data URL的支持；具体显示仍由邮箱客户端决定。外部HTTPS图片在站内信中显示为主动打开的链接；邮件客户端可能自动加载，发送者应考虑隐私。

脚本、事件属性、样式、表单、iframe、SVG及危险URL被后端过滤；不会执行管理员任意代码。请先预览实际安全正文与人数，再输入当前管理员密码确认发布。正文或范围改变后必须重新预览。重复提交同一次发布请求不会重复发送；每位管理员每分钟最多一封。

站内信默认发布；勾选“同步发送更新邮件”才使用后台TLS SMTP，且仅向已主动订阅的收件人发送。后台邮件配置支持现有热加载。每封邮件单独一个收件人，不共享邮箱名单；队列逐封发送，单次SMTP超时20秒。维护/更新前后可查看“发布记录与邮件投递”的待发、SMTP已接受及失败/状态不确定统计。SMTP接受不等于邮箱最终送达。

点击“撤回站内信与待发邮件”需再次输入当前管理员密码。撤回使信件不能重新读取并取消待发邮件；正在发送、已发送的邮件及收件人已看到的内容无法收回。用户取消订阅、收件人封禁、发布者失去管理员权限会取消尚未发送的邮件。服务重启时，未确认完成的SMTP事务标记失败，不自动重发，避免重复投递。

安全上限：全站最多1000封、200000条收件记录、单封最多10000位收件人。达到上限会拒绝新发布；撤回保留审计内容，不腾出容量。长期保留/清理和备份轮换由运营者制定；当前没有网页批量删除工具。后台不会显示邮件凭据，也不提供向任意未注册邮箱群发的接口。

## 注册与登录协议

注册及每次密码登录都必须主动勾选当前“隐私政策”和“使用协议及免责声明”，默认不勾选。链接在确认项旁，打开新页方便阅读。后端要求明确同意并核对当前站点资料/协议摘要，保存账号、版本和最近确认时间；未勾选或协议已变化会拒绝请求，不发登录Cookie。

站长在“外观、协议与公告”设置站名、运营者、隐私联系方式、数据说明和两个协议。默认站名WebTS；默认协议的 `{{site_name}}` 会自动替换为站名。修改协议或运营资料后，用户下次密码登录必须重新确认；已有会话不会仅因协议更新自动撤销，请通过公告/站内信通知重要变更。
