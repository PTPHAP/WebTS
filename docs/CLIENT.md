# 语音与服务器头像

WebTS 默认持续采集麦克风，并开启本地降噪与“仅保留人声”。音量表只显示处理后的电平，不以音量阈值决定开关。静音停止发送；按键发言在网页获得焦点时生效。使用耳机能减少回声。

“麦克风已开启”与“正在发言”独立：发言指示根据连续的实际音频帧更新，收到发言结束标记即熄灭，无标记时约250–350ms熄灭，独立的DTX维护帧不点亮网页指示。Opus协商开启DTX，静音时减少数据包，网关把只有帧头的静音包转为TS发言结束标记，并在静音、按键松开、切换耳语目标时结束旧语音流。接收原生客户端的空结束包不会断开网页，也不会把该控制包的序号误算成RTP丢包。麦克风轨道继续开启，不使用自定义音量阈值，不截断有效短音频帧；DTX周期性编码帧仍保留，部分原生客户端可能短暂显示活动。持续背景声也可能被编码器视为有效音频。[Opus RTP标准](https://www.rfc-editor.org/rfc/rfc7587.html)。

## 语音设置

### 仅保留人声

在“语音与设备”中默认开启，也可关闭恢复连续降噪；显式关闭的偏好会保留。已有浏览器偏好缺少此选项时采用开启，已关闭降噪的偏好仍保持关闭。修改后重新连接生效。

使用既有 RNNoise 模型输出的人声概率，在本地音频工作线程中抑制无人声时的残留底噪，未添加外部识别服务或音量阈值。约10ms回看、短暂句尾保留与渐变减少首字、尾字和切换爆音；新增回看延迟不等于总通话延迟。[固定处理组件](https://github.com/sapphi-red/web-noise-suppressor/blob/v0.4.1/src/rnnoise/processor.ts)、[RNNoise源码](https://github.com/shiguredo/rnnoise/blob/2022.1.0/src/denoise.c)。

这是基于人声检测的降噪，不能保证所有环境完全无杂音。极轻声、气音和特殊发声可能漏检，背景人声也可能被保留；不能识别哪一个人是本人，讲话与噪声重叠时仍依赖原降噪模型。若吞字，可关闭此项保持持续降噪。人声模式下主识别器初始化或运行失败会暂停麦克风发送并提示，仍可收听；重新连接重试，或断开后关闭此项。关闭人声模式时保留原来的直接音频回退。

### 降噪与设备处理

默认使用本地 RNNoise 降噪，并开启“键盘声消除增强”。在“语音与设备”中可以关闭键盘增强或关闭降噪；话筒增益与总收听音量可调整。话筒处理设置在下次连接时应用，收听音量即时生效。旧版本的原生降噪偏好会迁移到本地模式，原先明确关闭降噪的设置保留。

键盘增强使用 GTCRN → RNNoise 两级本地模型，抑制键盘和点击残留；不根据键盘事件静音，也不增加音量阈值门控。模型使用同源固定版本 WASM/48kHz AudioWorklet，不把音频发送到外部降噪服务，麦克风原生降噪请求关闭。键盘模型需要 WASM SIMD；不支持或模型失败时保留 RNNoise；主模型失败的发送策略由上面的“仅保留人声”选项决定，并明确提示。[固定处理组件](https://github.com/sapphi-red/web-noise-suppressor/tree/v0.4.1/src)、[GTCRN WASM](https://github.com/sapphi-red/gtcrn-wasm/tree/v0.0.3)。

两级增强会增加本机处理延迟和 CPU，GTCRN 内部按16kHz处理并重新采样，会影响高频音色。声音变闷或设备负担较高时，可以关闭键盘增强保留 RNNoise。效果因声音、设备和环境而异；不能保证所有键盘声完全消失，不能宣称与TS客户端算法或听感完全相同。

回声消除和自动增益使用浏览器设备能力，默认请求启用；本地降噪模型无法替代需要扬声器播放参考的回声消除。“当前”状态分别显示设备报告的回声/增益是否启用，未报告状态时不会显示已启用。有些设备可能忽略原生降噪关闭请求，界面也会注明。开启开关或报告已启用仍不等于实际回声听感验收。[媒体采集标准](https://www.w3.org/TR/mediacapture-streams/)。

麦克风被拒绝时，请在浏览器网站权限及系统设置中允许麦克风；也可先勾选“仅收听”。麦克风约束只会改善采集，不能解决目标服务器不响应UDP的网络问题。

## 头像互通

连接后在本人资料选择“设置服务器头像”。网页支持最大2MiB PNG/JPEG/WebP，解码前最大4096边长及8百万像素，裁剪为正方形并压缩成最大64KiB的PNG；服务端再次校验、清除元数据。上传绑定当前TS身份与服务器，由该身份的TS权限决定是否接收。

频道树、聊天和成员资料显示可见成员的经典服务器头像（PNG/JPEG/GIF，读取上限128KiB、512×512，GIF仅第一帧转为静态PNG）；失败会显示说明，可重新加载。网关只访问当前TS语音服务器同一IP上的文件端口，不接受任意图片路径或地址，限制大小、超时与并发。TS3通常需开放30033/TCP（以服务器实际设置为准），部署者应允许网关访问；网页接口无需额外公开文件端口。

**经典TS3头像文件传输没有语音链路加密，请只使用可公开图片。** 浏览器至网关仍受HTTPS/WSS保护，语音仍严格要求两段传输加密。[协议库文件传输实现](https://github.com/Moepchi/tsclientlib/blob/2e7794928f18d5aef2da5b48f420f9c801b1112c/tsclientlib/src/lib.rs)。

经典服务器头像和myTeamSpeak账号云头像是独立机制。本版支持服务器头像；云头像没有找到可供第三方网页网关使用的公开接口/授权契约，因此暂不显示。原生客户端可能优先显示云头像或使用自己的缓存，需检查其服务器头像设置。[官方头像说明](https://support.teamspeak.com/hc/en-us/articles/360002744997-Are-there-any-limits-on-the-avatar-size)、[官方SDK字段](https://github.com/teamspeak/ts3client-pluginsdk/blob/master/include/teamspeak/public_rare_definitions.h)。

## 频道与聊天

选择频道查看完整介绍，点击“进入此频道”加入，桌面也支持双击；中央固定展示当前频道介绍。先以空密码请求TS，由服务器验证权限，只有频道密码错误（781）才询问密码；无权限、超时等错误不会误当成密码问题。密码不缓存，错误密码可重试，取消或断开丢弃待处理切换；移动成员也走同一流程。

只渲染文字及有限的粗体、斜体、下划线和HTTP/HTTPS链接，不执行HTML、不自动加载介绍中的远程图片。频道聊天始终发往本人所在频道，查看另一频道不改变聊天目标。私聊需选择其他成员。

手机通过“频道 / 聊天 / 成员”切换，语音按钮常驻；核心按钮至少44px，按住发言不触发页面手势。输入框使用16px字体、适配屏幕键盘的可见高度和安全区域。移动语音仍为试验支持：系统切后台、锁屏、音频设备和浏览器限制需在实际手机上验证。

## 连接质量

语音设置中每2秒刷新浏览器↔网关WebRTC RTT、网关↔TS协议RTT、接收抖动、平均接收缓冲和累计接收丢包。缺失数据显示“—”，没有接收语音时不伪造零丢包。缓冲取本次连接累计等待秒数除以输出帧数，丢包为累计计数的比率；只显示数值摘要，不上传候选IP或原始统计。[WebRTC统计定义](https://www.w3.org/TR/webrtc-stats/)。

RTT是网络往返时间，不能相加当成说话到听见的总延迟。总延迟还包括设备采集、本地模型、编码、接收缓冲与播放；需通过两端实际音频测量验收。统计仅供定位网络和接收缓冲，本版没有宣称达到容量或端到端P95目标。

## 提示音

首次点击页面后启用本地生成的轻提示音：连接/断开、当前频道成员进入/离开、切换频道、收到消息、戳一戳、静音/收听切换及连接错误。默认音量15%，在语音设置可关闭、调节并试听；偏好只保存在当前浏览器。仅新事件播放，不重放历史消息；同类密集事件合并，避免连续轰鸣。

浏览器暂停或阻止自动播放时需要再次点击页面。提示音不申请麦克风、不从外部加载音效，不改变TS身份权限或实际语音发送。

TS权限由服务器验证，网页管理员身份不会赋予TS权限；无发言权限时会显示状态。截图和协议自动测试不等于真人语音听感、官方TS3/TS6兼容或容量正式验收。
