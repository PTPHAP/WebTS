# 网站账号与TeamSpeak身份

邮箱账号负责网站登录和找回；TS私钥证明实际身份，UID对应的服务器组和频道权限由TS服务器维护。

## 网页操作

- 导入TS3官方导出的.ini身份或兼容身份字符串，不能仅输入公开UID。
- 网页创建新身份，显示UID；新身份没有旧身份的权限。
- 一个账号保存多个身份，可改名、选择默认、导出和删除；重复UID去重。
- 导出身份前验证当前网站密码；导出文件含私钥，应保密并自行备份。
- 导出后在原生TS客户端导入，UID必须一致。TS6按照实际验证过的兼容导入或同步流程使用。
- 切换身份要重新连接，不能将两份身份的权限合并。
- 找回网站密码后身份密文保留，部署主密钥必须仍可用。

## 待验证

当前库内已验证INI/规范身份表示往返、混淆密钥恢复、UID与计数器保留、纯公钥/非法文件拒绝、账号归属及重复UID去重。数据层暂设单账号最多100个身份以限制存储，后续配额变化须同步文档。

网页与HTTP接口已提供上述操作，导出与删除要求当前密码，身份选择在连接时锁定，先断开再切换。仍需真实TS3原生文件和TS6客户端验收，不能把库内往返测试当作官方客户端兼容证明。

## 原生客户端互用

TS3：“工具 → 身份”选择并导出INI，在WebTS的身份管理中导入该文件，对照客户端高级信息中的UID。网页导出的INI含私钥，可在TS3身份窗口导入；确认UID一致后再连接原服务器。

新身份不复制旧身份权限。同UID重复导入会保留已有记录，不用不同名称制造重复身份。高安全等级服务器请先在原生客户端提高身份安全等级后重新导入；网站限制握手期间的自动耗时计算。

TS6服务端与TS6客户端是两个兼容门槛。本项目使用传统TS身份握手，不处理Stream/Call或myTeamSpeak登录凭据。先按官方客户端提供的TS3身份导入/同步方式迁移，再核对UID；未有真实客户端验收时不保证菜单位置或自动同步。不要导入myTeamSpeak密码。
