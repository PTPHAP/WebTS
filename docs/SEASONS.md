# 社区节日主题

1.0.8提供经典、新春·灯火、中秋·月泊、圣诞·冬信、万圣·夜游、跨年·星序六套内置外观。1.0.8主题使用固定配色与静态装饰，不要求额外服务，不下载第三方主题、字体、图片或脚本。

后续开发版补充内置矢量节日场景：新春灯笼/梅花/鞭炮，中秋满月/玉兔/月饼/桂枝，圣诞树/礼物/雪花/拐杖糖，万圣南瓜灯/巫师帽/蝙蝠/烛灯，跨年时钟/烟花/星屑/城市剪影。首页、顶部及频道标题按空间展示不同尺寸，主题预览使用同一组图形；上传的站点图片保持独立展示。此补充尚不属于已发布的1.0.8下载附件。

## 管理员预览与发布

进入“站点管理 → 外观、协议与公告 → 社区节日主题”，选择主题。预览只作用于编辑区域，其他用户与当前通话不会因预览而改变。

确认后填写当前管理员密码，点击“保存并发布首页”。保存沿用站点管理权限及服务器校验；网站管理员不会因此获得TS权限。经典为默认值，非法主题ID不能保存，不支持任意CSS、HTML、JavaScript或主题包上传。

## 成员选择

点击右上角个人账号，选择“外观 · 社区主题”：

- **界面亮度：** 深色或浅色，原顶部切换按钮继续可用。
- **跟随站点主题：** 使用管理员当前发布的主题。
- **始终使用经典：** 保留经典外观，不被后续节日发布覆盖。

设置随账号保存，其他浏览器登录后读取；已打开的页面沿用账号偏好同步机制。未登录访客采用站点公开主题。无法识别的浏览器端主题值回到经典，偏好尚未读取时也不会套用旧账号选择。

管理员保存后当前页面立即更新。其他可见页面复用既有约两分钟的构建检查，在页面重新可见时也会读取公开主题；不新增一个持续轮询。离线时保持现有外观，恢复后再同步。

## 通话与可访问性

主题切换只更新样式属性，不为主题重新建立语音连接、RTC对象、私信引擎或播放器。页面导航、真实网络故障与浏览器后台限制仍有各自边界，主题不能保证系统级后台通话能力。

开发版没有自动背景音乐或持续全屏粒子；节日物件使用CSS轻动态，保留浏览器减少动态效果设置。固定主题支持深浅色，编辑预览和成员选择支持320px窄屏。自动节日排程、农历日历、自定义皮肤及外部素材不属于本版。

开发版动态包括灯笼轻摆和梅花微动、流云和玉兔轻跃、树灯交替与雪花飘动、蝙蝠振翅与南瓜浮动、烟花展开与时钟秒针。紧凑图标保留主体轻动态；页面进入后台时暂停，开启“减少动态效果”时停用。图形不接收鼠标/触摸事件，不加载外链，不随麦克风电平反复渲染。经典模式完全移除节日图形及点击监听。

点击反馈使用对应的花瓣、星光、雪花、蝙蝠或彩屑；桌面最多3组、粗指针设备最多2组，同时限制触发频率，约1秒内自动回收。输入框、选择框、可编辑内容、对话框和播放器不触发；拖动、滚动、右键和多指操作不触发。不记录或上传点击位置、输入内容，不新增接口和存储。

## 升级与回退

升级前备份数据库、配置和原部署主密钥。旧站点没有主题字段时保持经典；旧编辑器提交其他首页字段不会覆盖新主题选择。

**从启用了节日主题的1.0.8回退到1.0.7之前，必须先在1.0.8选择“经典”并保存。** 经典保存会省略新主题字段，使旧版本严格配置读取器能够加载。不要先换旧二进制再尝试用旧后台关闭主题。

若新程序已无法运行，应先保留当前数据库及密钥，在隔离副本恢复并修复配置；必要时只恢复升级前的站点配置记录。这可能撤回升级后的后台配置编辑，应先核对，不能整库覆盖而丢失新私信、账号或举报。优先向前修复。性能、真实设备与独立安全验收范围见[发布门槛](RELEASE-GATES.md)。
